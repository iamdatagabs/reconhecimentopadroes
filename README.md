# Reconhecimento de Padrões — exercícios acadêmicos

Repositório de scripts e exemplos executados em atividades de **Reconhecimento de Padrões**.

## Contexto
Material de estudo para explorar preparação de dados, representação de atributos, métodos de classificação e avaliação de padrões. Consulte cada script para identificar bibliotecas, conjuntos de dados e métodos efetivamente utilizados.

## Reprodutibilidade
Antes de executar os exemplos, confira as dependências e a origem dos dados. Resultados de exercícios não devem ser interpretados como modelos validados para uso operacional.
